![Comic panel: Leo hangs a framed excellence poster while Vera watches with a raised eyebrow.](assets/images/organizational-values/comic-01-shiny-poster.jpeg)
**Panel 1:** *The hook: a proud new values poster goes up on the wall.*

![Comic panel: engineers argue at a whiteboard while the values poster hangs crooked and ignored behind them.](assets/images/organizational-values/comic-02-nobody-uses-it.jpeg)
**Panel 2:** *The problem: visible everywhere except where decisions are made.*

![Comic panel: Vera holds an excellence card next to a mirror reflecting it blank and asks if any rival would choose the opposite.](assets/images/organizational-values/comic-03-reversible-test.jpeg)
**Panel 3:** *Test one, reversible: if no successful company would choose the opposite, it is applause, not a choice.*

![Comic panel: Leo stands confused at a fork between ship fast and polish more, holding the values card upside down.](assets/images/organizational-values/comic-04-applicable-test.jpeg)
**Panel 4:** *Test two, applicable: if it cannot decide a speed-versus-quality call, it is a slogan.*

![Comic panel: Vera holds the values card beside a window showing the team behaving otherwise and asks if it describes them today.](assets/images/organizational-values/comic-05-honest-test.jpeg)
**Panel 5:** *Test three, honest: a value must describe how we actually behave now — or it teaches people the values are fiction.*

![Comic panel: Vera works alongside engineers practicing a new habit while a blank poster leans unwritten against the wall.](assets/images/organizational-values/comic-06-behavior-first.jpeg)
**Panel 6:** *The principle: behavior first, documentation second — the value records the change, it does not create it.*

![Comic panel: a well-worn values card with tabs for hiring, promotions, and decisions lies on the table between Vera and Leo.](assets/images/organizational-values/comic-07-values-in-use.jpeg)
**Panel 7:** *How it plays out: values live in hiring debriefs, promotions, and major decisions — used, not framed.*

![Comic panel: Vera holds the worn values card while the framed poster is carried away behind her.](assets/images/organizational-values/comic-08-no-poster-needed.jpeg)
**Panel 8:** *The closer: a value used weekly needs no poster.*
