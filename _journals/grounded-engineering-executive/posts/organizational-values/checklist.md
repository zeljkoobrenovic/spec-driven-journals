*The working checklist behind this principle, following the eight steps from clarifying purpose to maintaining and evolving. The Article tab carries the rationale, implications, and anti-patterns.*

### 1. Clarify the Purpose of Values

- [ ] Have we clearly articulated what decisions our values are meant to guide?
- [ ] Are our values intended to reinforce existing cultural changes (not magically create new ones)?
- [ ] Do senior leaders actively model these values?

### 2. Decide the Scope of Values

- [ ] Should we extend existing company values rather than create new ones?
- [ ] If needed, are we choosing intentionally between:
  - [ ] Company-wide values
  - [ ] Engineering values
  - [ ] Engineering leadership values
- [ ] Are the proposed values truly relevant to Engineering's work?

### 3. Evaluate Each Value for Quality

**Reversible**

- [ ] Can this value be reasonably reversed without sounding nonsensical?
- [ ] Does it represent a real strategic choice (not just a universally good statement)?
- [ ] Would another successful company reasonably choose the opposite?

**Applicable**

- [ ] Can this value guide real, complex decisions?
- [ ] Does it help in trade-offs (e.g., speed vs. quality, build vs. buy)?
- [ ] Can it be used in planning, hiring, performance reviews, and promotions?
- [ ] Would team members know how to apply it in a specific scenario?

**Honest**

- [ ] Does this value accurately describe how the organization behaves today?
- [ ] Are top performers already modeling this behavior?
- [ ] Is it grounded in reality rather than aspiration?
- [ ] If behavior needs to change, are we changing behavior first before documenting it?

### 4. Avoid Common Traps

**Identity Values**

- [ ] Is this more about how we want to *see ourselves* than about how we make decisions?
- [ ] Would someone rarely use this value when deciding what to do next?

**Vague Prioritization Values**

- [ ] Does this value actually help prioritize work?
- [ ] Does it provide context for trade-offs?
- [ ] Is it more than a slogan?

### 5. Plan the Rollout Carefully

- [ ] Have we waited long enough to understand the organization before introducing new values?
- [ ] Have we tested the values in small groups first?
- [ ] Did we involve key stakeholders early?
- [ ] Did we iterate before finalizing?
- [ ] Are we building buy-in rather than announcing top-down?

### 6. Integrate Values Into Daily Work

- [ ] Are values integrated into hiring (including allowing candidates to opt out)?
- [ ] Are values explicitly discussed during onboarding?
- [ ] Are promotions tied to value-aligned behavior?
- [ ] Do 1:1s and team meetings reinforce value-aligned accomplishments?
- [ ] Are values referenced in major decision discussions?

### 7. Align With Strategy

- [ ] Do the values reinforce and clarify the organization's strategy?
- [ ] Can each value act as a guiding principle for strategic decisions?
- [ ] Is the overlap between strategy and values intentional and coherent?

### 8. Maintain and Evolve

- [ ] Are we revisiting values periodically?
- [ ] Are we adjusting values as behavior and strategy evolve?
- [ ] Are leaders consistently held accountable for modeling them?
