*The working checklist behind this principle, grouped as the source organizes it: the drip first, then the moves for significant messages, then the final audit. The Article tab carries the rationale, implications, and anti-patterns.*

### Maintain the Drip (Consistent Updates)

- [ ] Send a short, regular update (e.g., weekly), even if nothing major happened.
- [ ] Include 1–2 human/personal sentences.
- [ ] Add key reminders about upcoming deadlines.
- [ ] Cover 2–3 important topics in short paragraphs.
- [ ] Include a brief bulleted list of smaller updates.
- [ ] Close with an invitation for questions and feedback.

### Extract the Kernel (Respond to Executive Feedback Effectively)

- [ ] Identify the underlying concern behind a question or suggestion.
- [ ] Avoid getting stuck debating incidental details.
- [ ] Confirm your understanding of the core issue explicitly.
- [ ] Reframe discussion around the real problem (e.g., speed, priority, risk).

### Test Before Broadcasting

- [ ] Identify if the message is significant or org-wide.
- [ ] Share the draft with at least one trusted reviewer.
- [ ] Ask specific individuals (not just a group) for feedback.
- [ ] Ask reviewers to flag:
  - [ ] Confusing areas
  - [ ] Unintended tone
  - [ ] Potential controversy
  - [ ] Missing context
- [ ] Revise before sending broadly.

### Build the Packet (Structure Every Important Communication)

**Summary Section**

- [ ] Start with a concise summary (tl;dr).
- [ ] Clearly state:
  - [ ] What changed
  - [ ] Who it applies to
  - [ ] What action is required
  - [ ] Key dates
  - [ ] Where to find more information
  - [ ] How to ask questions

**Canonical Source**

- [ ] Link to a single source of truth (doc/wiki).
- [ ] Ensure it is up-to-date.

**Questions**

- [ ] Provide a public place for questions (chat/email list).
- [ ] Name a contact person for private questions.

### Keep It Short

- [ ] Edit for brevity.
- [ ] Remove unnecessary background.
- [ ] Use bullets where possible.
- [ ] Cut anything that doesn't support the main message.

### Use Every Channel

- [ ] Share important updates via email.
- [ ] Share the same updates via chat.
- [ ] Reinforce in team meetings.
- [ ] Reinforce in larger org meetings (e.g., all-hands).
- [ ] Publish meeting minutes.
- [ ] Maintain weekly notes.
- [ ] Maintain a decision log.
- [ ] Ensure at least one person on every team is informed.

### Final Quick Audit Before Sending Any Major Message

- [ ] Is it regular and predictable?
- [ ] Did I extract the real issue?
- [ ] Did someone review it?
- [ ] Does it have a clear summary?
- [ ] Is it concise?
- [ ] Is it shared across multiple channels?
