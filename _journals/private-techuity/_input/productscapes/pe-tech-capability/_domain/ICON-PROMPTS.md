## KPI icon template

The 144 KPI nodes use the repository's `build_kpi_prompt` template from
`generate_missing_domain_icons_gemini_nanobanana_api.py`. Substitute each node's
`name` and `description` from `customers/customers.json` below. The icon filename
is `customers/icons/kpi-{customer-id}-{kpi-id}.png`.

```text
Create a square KPI icon for a product-strategy dashboard.

KPI: {name}
KPI description: {description}

Icon requirements:
- A minimalist icon in a clean, professional line-art style, no text.
- No text, or labels.
- No borders or frames.
- The design features bold, consistent black outlines with rounded stroke ends.
- Use thick, uniform line weights and simple geometric shapes.
- No shading, no gradients, and no colors, only high-contrast black and white vector-style graphics.
```

[Review the KPI icons](KPI-ICON-PREVIEW.html) at their 50-pixel display size.
