# Product brick icons

Generated on 8 September 2026 using the built-in `image_gen` tool. Each brick has
a distinct PNG asset in `../product-bricks/icons/`, named after its stable brick
ID. The images are illustrative capability metaphors, not official Vortex artwork.
The toolkit copies these source assets into the generated documentation and uses
the standard `<brick-id>.png` filenames in brick cards, detail pages, and linked
views. The architecture and brick IDs remain unchanged.

The final prompt for each asset combines the shared specification below with its
subject description from the table. Each asset was generated separately.
The final files preserve the tool's native 1254 × 1254 dimensions and RGBA
transparency. All 23 assets passed PNG integrity and transparency checks and a
visual review together; representative icons were also reviewed at 48 pixels.

## Shared specification

```text
Use case: logo-brand.
Asset type: one production PNG icon for a Productscape product-brick card and detail page.
Primary request: create a single professional monochrome capability icon in a consistent minimal outline family.
Style/medium: clean flat black line art, precise geometric shapes, rounded stroke caps and joins, uniform bold strokes. Small solid-black accents only when needed for legibility. No grayscale fills, no gradients, no shadows, no texture, no 3D.
Composition/framing: square 512 by 512 canvas, one centered compact symbol occupying about 72 percent of the width and height, generous empty margins, readable when reduced to a 48-pixel thumbnail. Use at most one main metaphor and one secondary cue. Transparent background with actual alpha, not a checkerboard drawing.
Text: none. Do not render letters, labels, numbers, currency symbols, captions, logos, signatures, watermarks, borders, or a surrounding app tile.
Context: an illustrative venture capital and private equity capability model; these icons are generic visual metaphors, not Vortex brand marks.
Subject:
```
