*The working tool behind this record. The Article tab carries the rationale and anti-patterns.*

## 1. My role

- [ ] Describe my role and goals in plain language
- [ ] State what I'm accountable for and to whom
- [ ] Note anything about scope that's likely to be unclear from the title alone

## 2. About me

- [ ] Describe my personality in a few honest sentences
- [ ] State my communication preferences
- [ ] State my boundaries
- [ ] Include at least one personal, non-work detail — the "good craic" note: what I'm like to be around, not just how I decide

## 3. Operating approach — cadence

| Cadence item | My commitment |
| --- | --- |
| 1:1s | Weekly or biweekly, consistent slot, tracked in a joint document (agendas, actions, goals, updates) |
| Team meetings | Weekly, as appropriate; both an update and a decision/work-review forum; come prepared |
| Quarterly planning sessions | Real pre-work and follow-up; kept manageable and distinct from any separate business-review meetings |
| Early career session | Held once, in the first few months of the relationship: history, choices made, ambitions |
| Personal goals review | Each person's top 3–5 personal goals (not team plans), reviewed roughly every 3–6 months; I share mine too |
| What to loop me in on | State explicitly what emails, docs, or team wins I want to be added to |

- [ ] 1:1 cadence stated and a joint doc set up
- [ ] Team meeting purpose stated (update + decision/work-review)
- [ ] Quarterly planning cadence stated
- [ ] Early career session scheduled in the first few months
- [ ] Personal-goals review cadence stated (3–5 goals, ~3–6 months)
- [ ] "What to loop me in on" stated explicitly
- [ ] Commitment made to personally meet everyone on the team within a few months

## 4. Management style — collaborative

- [ ] State that I like to discuss decisions and options as a group before deciding
- [ ] Name the tradeoff honestly: collaborative can mean slow to decide
- [ ] Give the escape hatch: "if you need a decision quickly, make sure I know it"

## 5. Management style — hands-off, with a stated exception

- [ ] State that I am not a micromanager and won't sweat details unless something looks off track
- [ ] State what I do when something does look off: raise the concern, plan communication together
- [ ] Name the exception: early in a new initiative or with a new team, I get closer to the work on purpose, so I can help later
- [ ] State the default: I expect decisions made without me; when brought to me, I put it back with "what do you want to do?"
- [ ] State the ask: tell me about big decisions brewing, even if you don't need me to make them

## 6. Management style — accountable and organized

- [ ] State that I take action items seriously and expect the same
- [ ] State my preference: renegotiate a deadline before it slips, not after
- [ ] State that I want to be told about big work efforts early, not caught last-minute
- [ ] State the expectation of ruthless prioritization under resource constraints

## 7. Management style — data-driven but intuitive

- [ ] State that I like consistent, reviewed data — but not torturing the numbers
- [ ] State the purpose of data explicitly: insight, not a substitute for judgment
- [ ] State my agreement to shared processes over everyone inventing their own
- [ ] State that I am intuitive about people, products, and decisions
- [ ] State the expected response to my intuition: treat it as a hypothesis, argue it out, bring data or counter-evidence
- [ ] State that I want to know people as whole selves, not only through work output

## 8. Management style — strategic and user-oriented

- [ ] State how I think about strategy: identify the big lever, the problem, the timing, the information needed
- [ ] State the daily question I hold myself to: "what's the most important thing I can do?"
- [ ] Name my own failure mode honestly (e.g., getting buried in email) and invite people to flag it
- [ ] State my interest in direct user/customer signal even though my leverage is at scale

## 9. Communication norms — 1:1s and email

- [ ] State what belongs in a 1:1 vs. what can wait for a written check-in
- [ ] State it's fine to reach out between 1:1s if needed
- [ ] State my email reading cadence: read within about 18 hours
- [ ] State the response rule: I only respond if asked something directly or asked a question
- [ ] State what to do if a response is owed and hasn't arrived: resend or ask directly
- [ ] Define "FYI" explicitly: for information only, no response required — and I extend the same courtesy

## 10. Communication norms — chat and meeting style

- [ ] State when it's fine to ping me anytime (important, timely, or short items)
- [ ] Set expectations on my response consistency (often in meetings)
- [ ] State the preference for a quick sync over a long email thread when that's faster
- [ ] State my documentation preference: plans documented (slides, docs, or spreadsheets — format doesn't matter), detail expected when it matters
- [ ] State my default involvement level in work in progress: happy to be included early, but will typically weigh in when asked or at final review

## 11. Feedback and results

- [ ] State that I give and receive feedback, and want it early when it's constructive
- [ ] Name the formal backstop: an official review session each quarter
- [ ] State my commitment to raise concerns in a timely way, not save them up
- [ ] State the redirect rule: anyone venting to me about someone gets my help telling that person directly — not a channel that lets it stop with me
- [ ] State the results commitment plainly: measure, measure, measure

## 12. Keep it current

- [ ] Note the date this document was last revised
- [ ] Share it with every new report in their first week
- [ ] Revisit it when role, team, or actual working habits change
- [ ] Test it: can a report quote back my decision style and my email norms unprompted?
- [ ] Invite the team to add to it and make it "a little more authorized"
