How I handle underperformance as one arc — documented feedback first, a PIP only if it persists, and a humane exit only if it still does not resolve — in eight panels.

**Panel 1:** *The hook: if a PIP surprises anyone, the manager already failed.*

![Comic panel: a manager notices a performance gap in a 1:1 but stays silent, the concern fading into an unspoken thought bubble.](assets/images/managing-underperformance/comic-02-the-quiet-gap.jpeg)
**Panel 2:** *The problem: silence about a gap is not mercy, it is a debt that grows.*

![Comic panel: a manager gives vague verbal feedback with no notes, the words dissolving into mist behind them.](assets/images/managing-underperformance/comic-03-verbal-only.jpeg)
**Panel 3:** *The wrong way: feedback with no date, no example, and no paper trail helps no one.*

![Comic panel: an executive points to a whiteboard arc reading DOCUMENT, PIP, MANAGE OUT, with DOCUMENT circled and emphasized.](assets/images/managing-underperformance/comic-04-document-first.jpeg)
**Panel 4:** *The principle: document early and in writing; a PIP is an escalation, never an opener.*

![Comic panel: a manager pins four connected letters on a corkboard showing a feedback loop, with an executive nodding approval.](assets/images/managing-underperformance/comic-05-four-letters.jpeg)
**Panel 5:** *How it runs: initial documentation, a progress update, then back on track or insufficient progress.*

![Comic panel: a manager and employee sit with a signed Performance Improvement Plan while a calendar shows a highlighted four-to-six-week span with weekly check-ins.](assets/images/managing-underperformance/comic-06-four-to-six-weeks.jpeg)
**Panel 6:** *The mechanic: four to six weeks, up to three improvement areas, weekly progress checks.*

![Comic panel: a manager points to an at-will and no-guarantee clause on a plan while the employee nods, unsurprised.](assets/images/managing-underperformance/comic-07-honest-about-stakes.jpeg)
**Panel 7:** *The cost: naming the stakes plainly is harder than softening them, but softening them is what blindsides people later.*

![Comic panel: a manager, an executive, and an HR partner sit together reviewing an eight-step checklist calmly.](assets/images/managing-underperformance/comic-08-managing-out-together.jpeg)
**Panel 8:** *The closer: managing out is a sequence you run with others, not a failure you carry alone.*
