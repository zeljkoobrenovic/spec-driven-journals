# Spec: Written Exercises

> Working doc for the post in this folder. The spec drives the post; the post
> is the artifact.

## Intent

State how I use a bounded, rubric-graded written exercise to test writing
directly in a hiring loop, rather than inferring it from interview
performance. The post turns the workbook's "Written Exercise Example" and
its grading rubric into an operating tool: a tightly scoped take-home
(~3 hours, a few pages, framed as a pre-read sent before a meeting), a
reference churn-analysis-and-retention-roadmap prompt, and a fixed 12-point
rubric — 3 points each on written communication, data analysis, customer
sense, and product sense — that maps to a strong-yes / yes / judgment-call /
no decision.

## Audience

Hiring managers and interviewers running loops for writing-heavy roles (so
they know how to scope and score a written exercise before they build one);
candidates indirectly, through the fairness the rubric produces; peer
executives comparing hiring tools. First-person declarative.

## Success criteria

- [x] **Principle is quotable** — highlight states "I test writing with a
      bounded, rubric-graded exercise, never with vibes" in one paragraph.
- [x] **The signal-before-scoring idea survives** — a well-constructed
      exercise signals whether the org's culture values timeliness and
      diligence, independent of the response's content.
- [x] **The numbers survive** — ~3 hours, a few pages, 4 skills at 3 points
      each, 12-point total, and the exact decision bands (11–12, 8–10, 7,
      ≤6).
- [x] **Both rubric tables reproduced** — the decision-band table and the
      four skill-scoring tables (poor/good/excellent) appear intact in the
      Checklist tab.
- [x] **Product sense and data analysis are precisely defined** — data
      analysis means translating data into actions and "so-whats"; customer
      sense means segments carried through the whole exercise, not named
      once.
- [x] **Credit is explicit** — References name Claire Hughes Johnson's
      *Scaling People* companion workbooks.
