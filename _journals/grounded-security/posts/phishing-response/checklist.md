*The working checklist behind this record — the employee-facing phishing checklist, from the pre-click verification habit through the warning signs, the after-a-click response, and the rules to remember. This is the handout version: written for every employee, not just responders. The Article tab carries the rationale and anti-patterns.*

## 1. Before Clicking a Link or Opening an Attachment

- [ ] Was I expecting this email, link, or attachment?
- [ ] Do I recognize the sender?
- [ ] Does the sender's email address match the person or organization it claims to be from?
- [ ] Is the message creating unusual urgency or pressure?
- [ ] Is it asking for a username, password, financial information, or other sensitive data?
- [ ] If the message appears work-related, have I verified the request with the sender through a separate trusted method?
- [ ] If the message contains a website link, have I checked that the URL is correct and uses `https://`?
- [ ] If anything feels suspicious, have I stopped and contacted the IT Help Desk?

## 2. Warning Signs: Something Feels Funny

- [ ] I logged in and was immediately sent back to the login page
- [ ] A website does not behave as expected
- [ ] I received an unexpected package, delivery, payroll, greeting card, or similar message
- [ ] I received a document claiming to contain sensitive information that I was not expecting

## 3. Warning Signs: Something Looks Funny

- [ ] An attachment opens with an unusual error or does not contain what was promised
- [ ] I am prompted to enable macros, install software, update a driver, or install a new media player
- [ ] A website looks familiar, but the URL is different
- [ ] I found an unknown USB drive, CD, DVD, or other removable media

## 4. Warning Signs: Something Sounds Funny

- [ ] Someone claiming to be from IT asks for my username or password
- [ ] A caller says they need immediate access to fix an issue I did not report
- [ ] A new vendor or unfamiliar person wants information about our systems, software, or environment
- [ ] Someone makes an unusual request while claiming to represent facilities, management, IT, or another department

## 5. If I Already Clicked or Opened Something Suspicious

- [ ] Stop interacting with the message, website, or attachment
- [ ] Do not enter any additional information
- [ ] Contact the IT Help Desk immediately
- [ ] Tell IT what I clicked or opened and what happened afterward
- [ ] Report whether I entered a username, password, or other sensitive information
- [ ] Follow IT instructions for password changes, device checks, or other response actions
- [ ] Report the incident quickly so IT can help protect other users and prevent the issue from spreading

## 6. If I Did Not Click the Link or Attachment

- [ ] Report the suspicious message to IT or through the organization's phishing-reporting process
- [ ] Do not forward the suspicious message to coworkers unless IT instructs me to do so
- [ ] Keep the message available if IT needs to review it
- [ ] Remember that other employees may have received the same attack
- [ ] Be alert for follow-up attempts from the same or a similar sender

## 7. Information That Should Be Reported

- [ ] Suspicious emails asking for usernames, passwords, banking information, software details, or other sensitive information
- [ ] Unexpected emails containing links or attachments
- [ ] Attempts by unauthorized people to access a computer, account, system, or workspace
- [ ] Requests involving protected health information (PHI) or other confidential information
- [ ] Suspicious phone calls, messages, websites, or removable media

## 8. Key Rules to Remember

- [ ] Do not click unexpected links
- [ ] Do not open unexpected attachments
- [ ] Never give your username or password to another person
- [ ] Verify unusual requests through a trusted communication channel
- [ ] When something feels, looks, or sounds suspicious, report it
- [ ] When in doubt, contact the IT Help Desk
